# Stanislav 3D

Моё портфолио с 3D-моделью и фирменным стилем Coon Clean.

[Открыть сайт](https://krugliakovstudy-eng.github.io/stanislav-3d-portfolio/)

## Запуск

```sh
node server.cjs
```

Сайт откроется по адресу http://127.0.0.1:4173. Можно также использовать Live Server в VS Code. Открытие HTML как обычного файла не подходит для загрузки 3D-модели.

## Что где находится

- `index.html` — главная и слайдер.
- `portfolio.html` — работы, фильтр и 3D-просмотр.
- `contacts.html` — форма заявки.
- `css/style.css` — стили для всех страниц.
- `js/` — меню, слайдер, фильтрация, форма и сцена Three.js.
- `models/gun_low.fbx` — модель; `images/` — её рендеры.
- `branding/` — презентация Coon Clean.

Three.js 0.179.1 хранится в `vendor/three`. [Лицензия MIT](vendor/three/LICENSE).

Форма проверяет поля и открывает письмо на `krugliakovstudy@gmail.com` через
`mailto:`. Посетитель отправляет письмо самостоятельно в своём почтовом приложении.
Есть копирование заявки и резервное поле для ручного копирования. Внешние сервисы
и сервер не используются; автоматическая отправка писем на GitHub Pages отсутствует.

Публикация через GitHub Pages: ветка `main`, папка `/ (root)`.

## Как разобраться в коде

Это обычный статический сайт: три HTML-файла, один CSS-файл и пять небольших
JS-файлов. Установка пакетов, сборка и фреймворки не нужны.

1. Начните с `index.html`: здесь структура главной страницы и два слайда.
2. В `css/style.css` стили идут по разделам: общие настройки, меню, главная,
   портфолио, 3D, контакты. В конце — адаптация для планшетов и телефонов.
3. `js/main.js` открывает и закрывает меню.
4. `js/slider.js` меняет активный слайд. Для автопереключения используется один таймер.
5. `js/portfolio.js` сравнивает категорию работы с выбранным фильтром и скрывает лишнее.
6. `js/form.js` проверяет четыре поля обычными условиями, готовит письмо и копирует заявку.
7. `js/three.js` создаёт сцену, камеру и свет, загружает FBX и подключает кнопки.
   Один материал используется для всех частей модели.

Чтобы добавить слайд, добавьте `article.slide` и кнопку `.slider-dot` в HTML.
Чтобы добавить работу, скопируйте карточку и укажите её `data-category`.
Файлы в `vendor/three` — готовая библиотека Three.js, изменять их не нужно.
